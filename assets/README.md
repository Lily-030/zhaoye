## 在 GitHub 网页上传

1. 打开仓库的 `assets` 文件夹。
2. 点击 **Add file → Upload files**。
3. 拖入素材，确认文件名完全一致。
4. 点击页面底部 **Commit changes**。

若视频大于 100 MB，GitHub 网页无法直接上传。建议压缩视频，或把视频放到 YouTube / Vimeo 后将页面改为嵌入播放器。
